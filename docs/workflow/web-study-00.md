# **Web制作勉強会 #00<br /><small>「創る」から「公開する」まで ― 現代のWeb制作を体験する</small>**

## **全体方針**

この勉強会では、HTML・CSS・JavaScriptの基礎学習を終えた制作スタッフが、HTML + CSS + JavaScriptでサイトを `Next.js`（JSのフレームワーク）を使って再構築します。

目的は、 `Next.js` を完全に習得することではありません。

実際の制作を通して、

- JavaScriptがWeb制作でどのように使われるのか
- UIを部品として再利用するとはどういうことか
- データから効率よくページを作るとはどういうことか
- JavaScriptライブラリを利用すると何ができるのか
- SCSSを使ってスタイルをどう整理するのか
- Gitで制作履歴を残すとはどういうことか
- ローカルでの制作・更新を公開まで自動でつなげるとはどういうことか

を体験します。

各自が、

```text
自分のPC
↓
自分のプロジェクト
↓
自分のGitリポジトリ
↓
自分のGitHubアカウント
↓
自分のGitHub Pages
```

という環境を持ちます。

最終的には、各自が制作したプロフィールサイトをWeb上に公開します。

---

## **実施構成**

```text
開発準備　環境構築編
↓
本編 第1章〜第14章
↓
各自のプロフィールサイト完成・公開
```

本編は原則として、

**1回2時間以内**

を想定します。

### **5. 便利なコマンドを作る**

今後頻繁に使用するコマンドには、ショートカットを設定します。

詳細なファイル一覧を表示できるようにするコマンド、

```
ls -lva
```

Macの標準シェルであるzshを前提として、ホームの`.zshrc`ファイルにショートカットを登録します。

この命令をターミナルで行います。

```
echo 'alias ll="ls -lva"' >> ~/.zshrc
```

次に、PCを再起動させて、設定を読み込ませるのですが、これと同じことを以下のコマンドを使って実行することができます。

```
source ~/.zshrc
```

確認します。

```
ll
```

これで、

```
ls -lva
```

と同じ内容が表示されれば成功です。

一応、ちゃんとエイリアスが登録されているかを確認する。

```
cd
ll
```

`.zshrc`を確認。ファイルの中身を見て確認してみる。

```
cat .zshrc
```



### **8. SSH鍵を作ってGitHubと接続する**

GitHubへ安全に接続するために、SSH鍵を設定します。

今後はVS Codeのターミナルから、

```bash
git push
```

などのコマンドを使って、自分のPCからGitHubへ制作データを送ります。

その際に、

**「このPCからの接続は、本人からの接続である」**

ことをGitHubに確認してもらうためにSSH鍵を使用します。

SSH鍵は、

```text
秘密鍵
公開鍵
```

の2つで構成されます。

```text
秘密鍵 → 自分のPCだけに保存する
公開鍵 → GitHubへ登録する
```

という関係です。

---

#### **8-1. SSH鍵がすでにあるか確認する**

VS Codeのターミナルで、

```bash
ls -la ~/.ssh
```

を実行します。

次のようなファイルがあるか確認します。

```text
id_ed25519
id_ed25519.pub
```

この2つが見つかった場合は、すでにSSH鍵が作られています。

```text
id_ed25519
→ 秘密鍵

id_ed25519.pub
→ 公開鍵
```

既存の鍵がある場合は、**削除したり上書きしたりしません。**

その鍵が何に使われているか分からない場合は、新しい鍵を作る前に確認します。

鍵がなければ、次へ進みます。

---

#### **8-2. SSH鍵がない場合は新しく作る**

次のコマンドを実行します。

```bash
ssh-keygen -t ed25519 -C "GitHubに登録したメールアドレス"
```

例えば、

```bash
ssh-keygen -t ed25519 -C "example@example.com"
```

です。

実行すると、鍵を保存する場所を聞かれます。

```text
Enter file in which to save the key ...
```

今回は標準の場所を使用するので、そのままEnterを押します。

続いてパスフレーズを聞かれます。

今回は設定しないため、そのままEnterを押します。

確認でもう一度聞かれるので、再度Enterを押します。

作成が完了すると、

```text
id_ed25519
id_ed25519.pub
```

の2つのファイルが作成されます。

---

#### **8-3. 作成されたSSH鍵を確認する**

もう一度、

```bash
ls -la ~/.ssh
```

を実行します。

次の2つがあることを確認します。

```text
id_ed25519
id_ed25519.pub
```

---

#### **8-4. 秘密鍵は絶対に共有しない**

ここは重要です。

```text
id_ed25519
```

は**秘密鍵**です。

秘密鍵は、

- GitHubへ貼り付けない
- メールで送らない
- チャットへ貼らない
- 他人へ渡さない

ようにします。

GitHubへ登録するのは、

```text
id_ed25519.pub
```

という**公開鍵だけ**です。

---

#### **8-5. ssh-agentを起動する**

次のコマンドを実行します。

```bash
eval "$(ssh-agent -s)"
```

成功すると、

```text
Agent pid ...
```

のような表示が出ます。

これは、SSH鍵を使った認証を管理する仕組みを起動しています。

---

#### **8-6. 秘密鍵をssh-agentへ登録する**

次のコマンドを実行します。

```bash
ssh-add ~/.ssh/id_ed25519
```

これで、このPCの秘密鍵をSSH接続で利用できるようになります。

---

#### **8-7. GitHubへ登録する公開鍵を表示する**

公開鍵の内容を表示します。

```bash
cat ~/.ssh/id_ed25519.pub
```

ターミナルに、

```text
ssh-ed25519 AAAA...
```

のような長い1行が表示されます。

**この1行全体が公開鍵です。**

この文字列をコピーします。

Macでは、次のコマンドを使って直接クリップボードへコピーすることもできます。

```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

---

#### **8-8. GitHubへ公開鍵を登録する**

GitHubへログインします。

```text
画面右上のアカウントアイコン
↓
Settings
↓
SSH and GPG keys
↓
New SSH key
```

へ進みます。

**Title**には、この鍵がどのPCのものか分かる名前を付けます。

例：

```text
Company Mac
```

**Key type**は、

```text
Authentication Key
```

を選択します。

**Key**欄には、先ほどコピーした、

```text
id_ed25519.pub
```

の内容を貼り付けます。

登録します。

---

#### **8-9. GitHubとのSSH接続を確認する**

VS Codeのターミナルで、

```bash
ssh -T git@github.com
```

を実行します。

初めて接続すると、

```text
Are you sure you want to continue connecting ...
```

のように確認される場合があります。

その場合は、

```text
yes
```

と入力してEnterを押します。

認証に成功すると、

```text
Hi ユーザー名! You've successfully authenticated...
```

のように、GitHubのユーザー名を含むメッセージが表示されます。

これで、

**自分のPCと自分のGitHubアカウントをSSHで接続できる状態**

になりました。

---

#### **8-10. すでにSSH鍵があった場合**

`8-1`で、

```text
id_ed25519
id_ed25519.pub
```

がすでに存在していた場合は、**新しく同じ名前の鍵を作りません。**

まず、

```bash
cat ~/.ssh/id_ed25519.pub
```

で公開鍵を確認し、今回GitHubで使用して問題ない鍵であれば、その公開鍵をGitHubへ登録します。
