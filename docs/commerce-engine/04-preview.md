# 4. 管理画面での記事プレビュー

## 今回の変更

ローカルの管理画面に「記事プレビューを開く・閉じる」を追加した。
下書き保存前の入力内容を表示する。DB書き込み・公開操作は行わない。
既存の公開サイトもまだdramas.jsを使う。

## 表示内容

- タイトル、レビュー見出し、Markdown本文。
- メイン画像と追加画像。非公開Storageの画像は期限付きURLで表示。
- 評価、シーズン数、年、ジャンル、配信先、Featured指定。
- 引用文・引用者、YouTube動画（確認ボタンを押した場合のみ読み込み）。

空の項目は未入力と示す。形式が不正な入力は案内を出し、入力内容は残す。
本文の生HTMLは描画しない。リンクは別タブで開く。
本文内の画像記法は案内に置き換え、画像欄の画像を使う。
Web用の装飾はSCSSに置き、保存する本文へ混ぜない。
これは管理用の確認表示で、公開ページの全体レイアウトの完全再現ではない。
プレビュー操作ではrevisionも公開状態も変わらない。

## ファイルの担当

新規追加：
- src/app/admin/ArticlePreview.jsx：入力中の内容を表示。
- src/app/admin/preview.module.scss：プレビューの装飾。
- docs/commerce-engine/04-preview.md：この説明。

変更：
- src/app/admin/DraftWorkspace.jsx：入力値をプレビューへ渡す。
- src/app/admin/admin.module.scss：開閉ボタンの装飾。

## 確認方法

1. /admin で既存原稿を選び、保存ボタンの下のプレビューを開く。
2. タイトル・見出し・本文・作品情報・画像が一致しているか確認する。
3. 未保存の文章変更がプレビューへ反映されることを確認する。
4. プレビューを閉じても入力内容が残ることを確認する。
5. 実際に保存する場合だけ下書き保存を押す。
