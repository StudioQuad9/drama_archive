# ドラマレビューの付随情報を入力する

## 変更の範囲

ローカル管理画面に、既存dramas.jsのmetadata相当の入力を追加した。
会社SupabaseのDB構造は変えない。保存時に既存articles.metadataへ書き込む。
GitHubへの送信や公開サイトの切り替えはこの段階では行わない。

## 入力する項目

- 評価（0〜10の整数）、シーズン数、作品の年
- ジャンル、配信先（1行1項目、配列として保存）
- Featured指定（真偽値）
- 引用文、引用者、YouTube動画ID
- メイン画像と追加画像のパスまたはURL

画像ファイルのアップロードと画像プレビューはまだ実装していない。
画像は既存public/pict内の /pict/... や http(s) のURLを記録できる。
原稿本文・付随情報とも未入力を許可する。数値の空欄はnullとして保存する。
既存の最低限の下書きでmetadataが空でも、フォームを開ける。
公開日時は将来の公開操作で付ける。slugは当面自動生成のまま。
Featuredは指定値を保存する段階で、1件に限定する処理は公開機能側で扱う。

## ファイルの担当

- DraftWorkspace.jsx：本文と付随情報をまとめて下書き保存する。
- DramaFields.jsx：付随情報の入力欄を表示する。
- drama-fields.mjs：入力文字列とDBの数値・配列・真偽値を変換・検証する。
- admin.module.scss：入力欄を配置する。

既存metadata内の未知の項目は維持する。本文のみの編集で消さない。
どの項目の変更も未保存判定の対象とし、保存失敗時は入力を残す。
版番号の一致を条件に、contentとmetadataを一度に更新する。

## 確認

/adminで保存済み原稿を開き、作品情報・画像パスを入力して下書き保存する。
再読み込み後に同じ原稿を選び、値が残っていることを確認する。
作品情報だけを変更しても保存ボタンが有効になり、未保存の確認が働くことを確かめる。
従来どおり公開サイトはdramas.jsを表示し続ける。
