# 5-1. 執筆用管理画面の整理

## 配置

左：保存済み原稿の検索、10件ずつの一覧、編集中の原稿の画像操作。
右：タイトル・見出し・本文、作品情報、YouTube動画ID、引用文・引用者。
引用は特集用の任意項目として残す。画像の変更も右側の下書き保存で保存する。

検索は本人の保存済み原稿すべてのタイトル・見出し・本文を対象にDBで行う。
検索ボタンで確定し、検索結果を更新日時の降順で10件ずつ取得する。
同じ更新日時ならID順で並べ、ページ間の順番を安定させる。
検索・ページ移動・一覧更新では右側の入力と選択記事を変えない。
別の記事を選ぶときだけ、未保存の変更がある場合に確認する。
保存後は検索条件を保って一覧を再取得する。保存記事が検索条件に一致しない場合や
別ページに位置する場合も、編集欄は保存した記事を表示し続ける。
DBスキーマ変更は不要。Featuredを1件に切り替えるDB処理とスライダー修正は別工程。

## ファイル

- DraftWorkspace.jsx：検索とページ分割、左右の配置、保存後の一覧更新。
- DramaFields.jsx：作品情報・動画・引用。画像の操作を切り出す。
- ArticleImages.jsx：画像アップロード・パス・プレビュー。

## 確認

検索・クリア・前後ページで編集中の入力が失われないこと。
本文にだけある語でも検索できること。未一致の検索が0件になること。
10件を超える場合にページを切り替えられること。
画像操作が左にあり、下書き保存後に画像参照が残ること。
