# 6. 公開サイトをDB読み込みへ切り替える

## 今回の変更

トップページでdramas.jsの代わりにarticle_publicationsだけを読み込む。
Next.jsのサーバー側から公開用キーを使い、訪問者と同じ権限で取得する。
管理者のブラウザのログイン状態やSecret keyは使わない。
articles（下書き）は読み込まない。失敗時に静的記事へ勝手に戻さない。
公開記事が0件の状態と、読み込みエラーを区別して表示する。

トップページはアクセスごとに取得する。公開・更新・非公開後はページを
再読み込みすると反映する。すでに開いた画面の自動リアルタイム更新は行わない。
公開日時順に100件ずつ取得して全件を集め、既存の検索・ジャンル絞り込みへ渡す。
カード、詳細モーダルは既存の表示部品をそのまま使う。
未入力の作品情報は空配列・nullなどに整えて、表示が止まらないようにする。

## この段階の画像

/pict/... とhttp(s)の画像は表示できる。
非公開Storage画像の一般向け配信は07で実装するため、06では「画像準備中」を表示する。
DBに保存したStorage参照は変更しない。秘密の閲覧URLをページへ漏らさない。
Featuredは公開版のfeatured=trueを選び、通常一覧からは除く。
Featuredのクリック動作とスライダー上の装飾調整は次工程。

## 既存の記事

既存8記事はまだDBへ移していないので、この切り替え後はトップに出ない。
src/data/dramas.jsに元データを保持し、後の移行で使う。

## ファイル

- src/lib/articles/publications.js：公開DBを匿名権限で取得。
- src/lib/articles/publication-record.mjs：DB行を既存の表示用データへ変換。
- src/app/page.js：取得結果を一覧へ渡す。
- DramaArchive/index.jsx：静的データの直接読み込みを廃止。
- DramaCard/index.jsx、FeaturedDrama/index.jsx、ImageSlider/index.jsx：未入力値と外部画像への対応。
- public/pict/image-pending.svg：画像配信接続前の表示。

## 確認

管理画面で公開したテスト記事だけがトップページへ出ることを確認する。
未公開の原稿は出ないこと。公開記事を下書き保存しただけでは表示が変わらず、
更新すると変わること。非公開にして再読み込みすると消えることを確認する。
画像のStorage配信と既存記事移行がまだのため、この段階の画面は完成版ではない。
DB構造の追加や移行は今回行わない。Vercel公開前には接続用の環境変数を設定する。
